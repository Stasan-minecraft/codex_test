# AutoCraft — Fabric 1.16.5

Клієнтський мод автоматичного крафту у верстаку.

- кнопка «Автокрафт» під інтерфейсом верстака;
- меню рецептів з іконками та пошуком;
- вибір кількості або нескінченного режиму;
- автоматичне розкладання інгредієнтів;
- зупинка при досягненні ліміту, нестачі ресурсів, закритті верстака чи натисканні «Стоп»;
- серверу встановлювати мод не потрібно.
